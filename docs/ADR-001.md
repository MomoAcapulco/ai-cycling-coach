# ADR-001 — Java + Python hybrid architecture

**Status:** Accepted (Sprint 1)

## Context
The product needs maintainable APIs, AI tools, Bluetooth Low Energy communication on macOS and Linux, and predictive ML.

## Decision
- Java 21 and Spring Boot for the primary backend.
- Python for an isolated BLE/FTMS trainer adapter and, later, scikit-learn models.
- React/TypeScript for the web client.
- REST localhost contracts for the initial proof of concept, rather than premature microservices.

## Consequences
+ Java expertise and Spring AI ecosystem remain available.
+ Python/Bleak allows a cross-platform Bluetooth adapter.
- Two runtimes, more packaging and integration tests.
- FTMS/virtual gearing support remains unverified on the actual KICKR CORE 2.

## Safety
No FTMS resistance commands are implemented in Sprint 1. Physical hardware control will be guarded and separately tested.
